# Pokéllector
Pokéllector is a pokemon information and collection tracker site. it allows the user to view a wide variety of information about each pokemon, and create collections, either custom or from a preset, that can be used to track progress when collecting pokemon.


# Getting Started
Since there is no backend or database, all you have to do to run the project is npm i to make sure you have everything installed them run ng serve --open in the terminal and it will open the localhost in your browser


# Tech Stack
This app is purely built in angular - and by extension uses typescript over javascript. There is no backend yet, hence no backend framework, and there was no need for a database, all relevant data is stored in local storage
